# Проверка Launchpad — 6 сентября 2026

## Исправления

- Перелистывание использует смещение заранее смонтированных соседних страниц вместо появления и удаления страницы с переходом.
- Один жест трекпада перелистывает одну страницу; инерция не запускает повторный переход. Направление жеста фиксируется, вертикальные движения не перелистывают сетку.
- Повторное открытие показывает выбранную страницу, согласованную с индикатором. Учитывается системное уменьшение движения.
- Точки страниц стали кнопками с увеличенной областью нажатия и названиями для VoiceOver.
- Большие папки имеют вертикальную прокрутку. Добавлены команды извлечения приложения и показа в Finder.
- Ошибка запуска отображается пользователю; окно закрывается после успешного запуска. Ошибки удаления также отображаются.
- Ошибка проверки обновления больше не выглядит как отсутствие новой версии.

В отдельном debug-приложении с тестовой раскладкой через Accessibility API подтверждены: переход на вторую страницу, повторное открытие на ней, поиск конкретного приложения, запуск безопасного тестового приложения и закрытие Launchpad после запуска. Папка с 40 приложениями открыта и визуально проверена: панель помещается в окно, содержимое ограничено прокручиваемой областью.

Debug-режим `--ui-test` работает только вместе с `LAUNCHPAD_SUPPORT_DIR`: отключает сканирование, начальную настройку, аппаратные жесты и автоматическую проверку обновлений для изолированных проверок.

## Ограничения

Физическая плавность трекпада и частота кадров не измерялись. Синтетические события ввода доставлялись macOS нестабильно, поэтому не считаются доказательством полного GUI-покрытия. Перетаскивание проверено на уровне модели, а не полным физическим жестом. Не выполнялись удаление пользовательских приложений, установка удалённого обновления, изменение автозапуска, выход из сеанса и проверка после сна. Работа VoiceOver целиком не проверялась.

Ручная проверка на устройстве: короткие и длинные горизонтальные свайпы, диагональные и вертикальные движения, инерция, колесо мыши, быстрые последовательные свайпы, прокрутка большой папки, перенос между страницами и папками, горячая клавиша после сна. Каждый горизонтальный жест должен давать не более одного перехода без повторного скачка от инерции.
